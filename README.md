# Maison Roblox - Rudeus

Un script Roblox pour créer une maison explorable avec plusieurs pièces, mobilier, et interactions.

## Fonctionnalités

✨ **Structure complète de la maison**
- Entrée avec porte
- Salon avec canapé et table
- Chambre avec lit
- Cuisine avec table et chaises
- Salle de bain
- Escaliers (étage supérieur optionnel)

🚪 **Interactions**
- Portes interactives qui s'ouvrent/ferment
- Lumières contrôlables
- Télévision fonctionnelle

🎮 **Caméra**
- Système de caméra pour explorer la maison
- Vue première personne

## Installation

1. Ouvre Roblox Studio
2. Copie le code depuis `src/main_house_builder.lua`
3. Colle-le dans ServerScriptService
4. Lance le jeu et explore la maison !

## Structure des fichiers

- `src/main_house_builder.lua` - Script principal qui construit la maison
- `src/door_handler.lua` - Gestion des portes interactives
- `src/light_handler.lua` - Gestion des lumières
- `src/furniture.lua` - Création du mobilier

## Personnalisation

Tu peux modifier les couleurs, la taille, et les matériaux en éditant les valeurs RGB et les dimensions dans les scripts.
